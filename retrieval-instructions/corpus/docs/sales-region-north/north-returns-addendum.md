## How this addendum works
This addendum applies to AnySmartProduct-5 and AnySmartProduct-6 units bought in Sales Region North. It replaces the return window and the restocking fee of the global returns policy for those units. The rest of the global returns policy still applies, including the purchase-region rule.

## Sales Region North return window
Units bought in Sales Region North can be returned within 40 days of the delivery date. Opened units can be returned if all accessories are included.

## Sales Region North restocking fee
Opened units carry a restocking fee of $15.00. Unopened units in sealed packaging carry no fee.

## Holiday return extension
The holiday return extension notice applies in Sales Region North. For purchases inside the extension period, the later of the extension date and the normal Sales Region North window applies.

## Starting a return
Contact Sales Region North support with the order number. Sales Region North support issues the return authorization and a prepaid label.

## Units bought in another sales region
Returns of units bought in another sales region follow that sales region's rules. Sales Region North support does not process them and refers the customer to the global support contacts.
