## Archive notice
This document is no longer in force. It is kept so that support can explain how returns worked for orders placed before 2026-02-01. For any order placed on or after 2026-02-01, use the global returns policy v2.0 and the regional returns addenda.

## Former return window
Under this archived policy, a customer could return a unit within 21 days of the delivery date. The window was the same in every sales region. There were no regional returns addenda.

## Former restocking rules
Opened units carried a restocking fee that was set per order by the support agent. There was no fixed fee. Unopened units carried no fee.

## Former process
1. Email the support team with the order number.
2. Wait for a return authorization.
3. Send the unit back at the customer's own cost.

## Why it changed
The 2026 policy introduced fixed fees, prepaid labels and regional addenda so that each sales region can match its local consumer terms.
