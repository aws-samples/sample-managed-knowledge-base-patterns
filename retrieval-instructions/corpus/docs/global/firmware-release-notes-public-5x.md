## How to update
Firmware for the AnySmartProduct-5 updates over the home network. AnySmartProduct-6 room sensors receive their firmware through the AnySmartProduct-5 they are paired with. To check the installed version, open Settings, then About on the AnySmartProduct-5, or open the sensor page in the companion app.

## 5.3.3 (released 2026-09-15)
- Fixes unexpected restarts of some AnySmartProduct-6 room sensors that were seen after updating to 5.3.2.
- Improves battery level reporting on the AnySmartProduct-6.
- Recommended for every AnySmartProduct-6 that runs 5.3.2.

If a sensor keeps restarting after 5.3.3 is installed, contact support for the sales region where it was bought.

## 5.3.2 (released 2026-08-04)
- Adds a weekly program copy function on the AnySmartProduct-5.
- Improves pairing time for new AnySmartProduct-6 sensors.
- Known issue: a small number of AnySmartProduct-6 sensors may restart unexpectedly. Fixed in 5.3.3.

## 5.3.1 (released 2026-06-10)
- Adds humidity alerts.
- Fixes a display brightness issue at night.

## 5.2.0 (released 2026-03-02)
- New scene editor on the AnySmartProduct-5.
- Supports up to 24 room sensors per controller.

## Support for older releases
Units on any 5.x release can update directly to 5.3.3. AnyCompany recommends always installing the latest public release before contacting support about a fault.

These notes describe public changes only. AnyCompany does not publish internal diagnostics or root-cause analysis in the public release notes.
