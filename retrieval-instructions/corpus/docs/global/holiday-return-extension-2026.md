## What the extension does
Units bought from 2026-11-15 to 2026-12-31 can be returned until 2027-01-15. If the normal return window of the sales region of purchase ends later than 2027-01-15, the later date applies. The restocking fee of the sales region of purchase still applies to opened units.

## Which sales regions it covers
- Global base policy: applies.
- Sales Region North: applies.
- Sales Region Central: applies.
- Sales Region South: does not apply. Sales Region South returns follow the Sales Region South returns addendum all year.

## Gifts
Gifts bought in the extension period are covered in the same way. The gift receiver can start the return with the order number.

## Examples (global base policy)
- Bought 2026-11-20, delivered 2026-11-22: normal window ends 2026-12-22, so the extension date 2027-01-15 applies.
- Bought 2026-10-30: outside the extension period, so the normal window applies.

## How to use the extension
Start the return in the usual way with the support team for the sales region of purchase. Support applies the extension automatically when the order date is inside the period.
