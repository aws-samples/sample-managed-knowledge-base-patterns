## What this notice covers
This notice explains how long AnyCompany keeps device usage data from the AnySmartProduct-5 and AnySmartProduct-6 and from the companion app. Device usage data means scene runs, sensor readings, firmware update results and error reports.

## Retention period
AnyCompany keeps device usage data for 18 months from the date it is collected. After that, the data is deleted or reduced so that it no longer relates to a household.

## What is kept for a different period
- Order and invoice records are kept for as long as accounting rules require. They are not device usage data.
- Support tickets are kept under the support records schedule, which is separate from this notice.

## Customer choices
Customers can turn off optional usage reporting in the companion app under Settings, then Privacy. Turning it off stops new optional data from being collected. Data needed to deliver firmware updates is still collected.

## Changes from LC-104 v1.0
LC-104 v1.0, effective 2025-07-01, set a longer retention period. LC-104 v2.0 shortens the period. Data collected before 2026-07-01 is also covered by the new period.
