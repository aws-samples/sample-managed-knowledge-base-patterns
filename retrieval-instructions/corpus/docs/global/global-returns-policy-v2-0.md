## Purpose
This policy sets the global base rules for returning an AnySmartProduct-5 or AnySmartProduct-6 for a refund. It applies in every AnyCompany sales region unless that sales region publishes a returns addendum. A returns addendum replaces the return window and the restocking fee for units bought in that sales region.

## Return window
Under the global base policy, a customer can return a unit within 30 days of the delivery date. The unit can be opened. All accessories that came in the box must be included.

## Restocking fee
Opened units carry a restocking fee of $10.00 under the global base policy. Unopened units in their original sealed packaging carry no restocking fee. The fee is taken from the refund amount.

## Purchase-region rule
The return window and the restocking fee of the sales region where the unit was bought apply. Where the customer lives today does not change this. For example, a unit bought in one sales region and later moved to another sales region is still returned under the rules of the sales region of purchase. If a customer cannot show where the unit was bought, support uses the sales region on the original order record.

## Holiday purchases
Units bought during a holiday return extension period may have a later return date. See the holiday return extension notice for the current period and the sales regions it covers.

## How to start a return
1. Contact the support team for the sales region of purchase. Customers without a local team use the global support contacts.
2. Give the order number and the delivery date.
3. Support issues a return authorization and a prepaid label.
4. Pack the unit with all accessories and send it within the return window.
5. The refund is issued to the original payment method after inspection.

## What cannot be returned for a refund
- Units with damage from drops, liquid or an incorrect power supply. These can still be assessed under the warranty policy.
- Units with the serial label removed.
- Reconditioned units outside the reconditioned units return window.

## Refund versus warranty claim
A return gives the money back. A warranty claim repairs or replaces a faulty unit. A customer outside the return window may still be inside the warranty term, so support should check both.
