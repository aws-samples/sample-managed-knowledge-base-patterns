## Superseded notice
This version is no longer in force. A newer version of LC-104 took effect on 2026-07-01. This copy is kept so that customers and agents can see what applied before that date.

## Former retention period
Under LC-104 v1.0, AnyCompany kept device usage data for 36 months from the date it was collected.

## Former scope
Device usage data meant scene runs, sensor readings and error reports. Firmware update results were not listed in v1.0.

## Former customer choices
Customers could ask support to stop optional usage reporting. There was no setting in the companion app.

## Why it was replaced
The newer version shortens the retention period, adds firmware update results to the scope, and adds an in-app privacy setting.
