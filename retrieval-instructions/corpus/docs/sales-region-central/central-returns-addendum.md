## How this addendum works
This addendum applies to AnySmartProduct-5 and AnySmartProduct-6 units bought in Sales Region Central. It replaces the return window and the restocking fee of the global returns policy for those units. The purchase-region rule of the global returns policy still applies.

## Sales Region Central return window
Units bought in Sales Region Central can be returned within 45 days of the delivery date. Opened units can be returned if all accessories are included.

## Sales Region Central restocking fee
Opened units carry a restocking fee of $12.00. Unopened units in sealed packaging carry no fee.

## Holiday return extension
The holiday return extension notice applies in Sales Region Central. For purchases inside the extension period, the later of the extension date and the normal Sales Region Central window applies.

## Starting a return
Contact Sales Region Central support with the order number. Sales Region Central support issues the return authorization and a prepaid label.

## Units bought in another sales region
Returns of units bought in another sales region follow that sales region's rules. Sales Region Central support refers those customers to the global support contacts.
